# Datos

Los datos no se incluyen en el repositorio. Se descargan desde Kaggle:

- Uber Ride Price Prediction: <https://www.kaggle.com/datasets/kushsheth/uber-ride-price-prediction>
- Thyroid Disease Data: <https://www.kaggle.com/datasets/jainaru/thyroid-disease-data/data>

Después de descargarlos, los archivos deben quedar en estas rutas:

```text
data/raw/uber/uber.csv
data/raw/thyroid/Thyroid_Diff.csv
```

Los archivos originales no se modifican. Toda la limpieza se hace en memoria dentro de los notebooks y está justificada en cada uno.
